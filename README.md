### 🐛 [bug-zoo](https://github.com/MilkteaTW1/bug-zoo)
Turn your error messages into collectible monsters. A terminal bestiary for developers: fix the bug to catch it, then battle friends. No server, no accounts.
把錯誤訊息變成可收集的怪物。修好 bug 就能捕獲,還能跟朋友對戰,不需要伺服器或帳號。

```bash
npm install -g bug-zoo
bugzoo setup
```
